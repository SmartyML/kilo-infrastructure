# Backup und Wiederherstellung

## Grundsatz

Die eigentliche Sicherungsstrategie wird passend zur späteren Rolle dieses Containers ergänzt.

Vor riskanten oder destruktiven Änderungen muss geprüft werden, ob eine aktuelle Sicherung oder ein geeigneter Wiederherstellungspunkt vorhanden ist.

## Relevante Bereiche

- Systemkonfigurationen
- Anwendungsdaten
- `/root/admin`
- anwendungsspezifische Datenbanken oder Volumes

## Wiederherstellung

Konkrete Wiederherstellungsschritte werden nach Installation des eigentlichen Dienstes dokumentiert.
